Comment l'utilisateur choisit-il la référence de chaque extrémité ?

3 approches pour sélectionner intérieur / extérieur / axe lors de la pose d'une cote

A

Toggles I / E / A dans le popup de cote (recommandé)

L'éditeur de cote existant gagne deux lignes — une par extrémité — pour choisir la référence. Chaque extrémité est indépendante → mixte possible.

Cote
Type
H V L
cm
Début
I E A
Fin
E I A

Pour

  • Mixte naturellement possible
  • Discret, cohérent avec l'existant
  • Changeable après coup

Contre

  • Le popup s'allonge un peu
B

Snap sur la face lors du clic (outil DIMENSION)

En mode DIMENSION, survoler un mur fait apparaître 3 points de snap : face intérieure (vert), axe (violet), face extérieure (bleu). Le clic pose la cote sur le point le plus proche.

● Face intérieure ● Axe ● Face extérieure

Pour

  • Direct et spatial
  • Mixte possible si chaque clic choisit

Contre

  • 3 points proches sur mobile = difficile
  • Refonte du hit-testing
  • Non modifiable après coup
C

Mode global dans la toolbar DIMENSION

La toolbar affiche un sélecteur de référence (I / E / A) avant de cliquer. Tous les points posés dans cette session utilisent ce mode. Pour un mixte, il faut changer le mode entre les deux clics.

Référence active
Réf. I E A
→ cliquer 1er point, changer mode, cliquer 2ème point

Pour

  • Simple, toujours visible

Contre

  • Mixte = 2 actions distinctes, peu intuitif
  • Risque d'oublier de changer le mode
