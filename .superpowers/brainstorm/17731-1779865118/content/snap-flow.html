Flow de l'outil DIMENSION — style CAD

Validation du comportement attendu étape par étape. Dites-moi si cela correspond à ce que vous imaginez.

Face intérieure (I) Axe / milieu (A) Face extérieure (E) Point de référence confirmé
1

Hover sur un mur → 3 points de snap apparaissent sur la face

Face intérieure (vert), axe (violet), extérieure (bleu). Le point le plus proche du curseur se met en évidence. Aussi disponible sur les cloisons et zones.

2

Clic → 1er point de référence confirmé

Le point snapé s'affiche en orange avec sa lettre (I/A/E). Une ligne de preview suit le curseur en montrant la distance en temps réel.

3

Hover sur un 2e mur → mêmes snaps

Le preview montre la cote en continu. Possible vers n'importe quel élément : mur, cloison, nœud de zone.

4

Clic → popup de valeur, type auto-détecté (H / V / L)

La popup indique la référence choisie (ex. Cote I→E). L'utilisateur saisit la valeur désirée → contrainte stockée. L'outil reste en DIMENSION pour la cote suivante.
