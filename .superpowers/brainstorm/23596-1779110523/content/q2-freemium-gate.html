Question 2 sur 5 — Où mettre le verrou payant ?

Le "gate" définit la valeur perçue du plan Pro. Trop restrictif = frustration. Trop généreux = personne ne paie.

A

Limite de projets

Gratuit : 3 projets max, stockage local (navigateur).
Pro : projets illimités + sauvegarde cloud (sync multi-appareil).
Simple à comprendre, facile à implémenter.

B

Fonctionnalités avancées

Gratuit : plan + calepinage de base.
Pro : export PDF pro, partage client (lien de consultation), multi-pièces avancé, historique des versions.
Plus de valeur perçue, mais plus de dev.

C

Collaboration équipe

Gratuit : usage solo complet (comme aujourd'hui).
Pro : multi-utilisateurs, espace de travail partagé, droits par rôle.
Cible directement les PME. Solo garde 100 % des fonctions.
