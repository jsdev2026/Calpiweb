Question 4 sur 5 — Stack backend & auth

L'app est aujourd'hui 100 % navigateur (IndexedDB). Le SaaS nécessite un backend pour les comptes, le cloud et les paiements.

A

Supabase (recommandé)

Auth : email/password + Google OAuth intégré.
Base de données : PostgreSQL hébergé, API auto-générée.
Paiements : Stripe (intégré séparément).
Hosting : Vercel (Next.js natif).

✓ Open-source · Gratuit jusqu'à 2 projets Supabase · Déploiement rapide
B

Clerk (auth) + PlanetScale (DB)

Auth : Clerk gère tout (UI, sessions, OAuth) — zéro code auth.
Base de données : PlanetScale MySQL serverless.
Paiements : Stripe.
Hosting : Vercel.

⚡ Auth la plus rapide à intégrer · Payant au-delà du free tier
C

NextAuth + PostgreSQL (self-managed)

Auth : NextAuth.js (bibliothèque Next.js officielle).
Base de données : PostgreSQL sur Railway ou Neon.
Paiements : Stripe.
Hosting : Vercel.
