A — Scroll automatique

Les bandeaux se replient automatiquement quand on scroll dans le plan ou les coupes. Une mini-barre reste visible avec un bouton "▲ Afficher" pour les restaurer.

B — Bouton toggle

Un bouton "▲ Réduire / ▼ Développer" dans le header permet de replier/déplier manuellement. L'état est mémorisé. Contrôle explicite, pas de surprise.

C — Poignée drag

Une barre de séparation draggable entre les bandeaux et le plan permet de redimensionner librement. Très flexible mais plus complexe à implémenter.
