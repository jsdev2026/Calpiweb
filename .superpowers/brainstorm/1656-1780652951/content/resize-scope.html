A1 — Redimensionnement physique

Les nœuds du plan bougent réellement. La modification se reflète dans l'éditeur de plan ET dans le calepinage. La quantité de carreaux est recalculée.

Pour

  • Modification permanente
  • Plan et calepinage toujours cohérents

Contre

  • Complexe : quel bord bouge ?
  • Risque de casser le plan

A2 — Simulation dans le calepinage uniquement

Le plan reste intact (280 cm). Dans le calepinage, la pièce est simulée à 300 cm pour calculer la quantité de carreaux. Utile pour devis prévisionnels.

Pour

  • Plan protégé
  • Idéal pour simulation / devis

Contre

  • Plan et calepinage désynchronisés
  • Besoin d'indiquer visuellement l'écart
